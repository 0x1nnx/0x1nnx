## `> About Me`

Hey! I'm Inna, a cybersecurity student with a broad curiosity for everything happening across the cybersecurity landscape.

My main interest lies in penetration testing and offensive security — understanding how systems work, finding where they break and thinking like an attacker so that better defenses can be built.

I'm constantly learning through:

*  Penetration Testing & Offensive Security
*  Hands-on Security Labs
*  Capture The Flag (CTF) Challenges
*  Vulnerability Discovery & Analysis
*  Personal Cybersecurity Projects
*  Continuous Research & Learning

```text

```

My goal isn't simply to collect certifications or memorize tools.

I want to understand what is happening under the hood.

Understanding that perspective helps reveal weaknesses that might otherwise remain hidden — and ultimately helps create stronger systems.
